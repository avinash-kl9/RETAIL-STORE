RETAIL STORE MANAGER — QUICK START

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to launch the app in Chrome, Edge or Firefox.
4. Click “Add product” to enter your store products.

FEATURES
- Add, edit and delete products
- Product name, SKU/code, category, price, quantity and description
- Search products by name, SKU or category
- Filter by category, low stock and out of stock
- Dashboard totals: products, stock units, low-stock products and inventory value
- Saves data in the browser using localStorage
- Responsive layout for desktop and mobile

IMPORTANT
This is a front-end starter app. Data is stored only in the browser and device where you use it.
It does not yet include user accounts, cloud sync, barcode scanning, invoices, purchase records,
or multi-user access. Clearing browser site data may remove saved products.
